
# 📊 Task 8: Superstore Sales Dashboard

## 📁 Dataset Used
- **File:** superstore_sales.csv
- **Key Columns:** Period, Region, Group, Sub-Category, Sales (USD), Profit (USD), Quantity, Discount

## 🧰 Tools
- Power BI Desktop

## 🎯 Objective
Design a simple interactive sales dashboard that shows:
- Sales trends over time
- Sales by region
- Sales by product group or sub-category

## 📈 Visuals Created
1. **Line Chart:** Sales over Period (Month-Year)
2. **Bar Chart:** Sales by Region
3. **Donut Chart:** Sales by Group (or Sub-Category)
4. **Slicer:** Region or Group filter
